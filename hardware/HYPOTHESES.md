# Inferred, not yet shown: a test list for four units

Part of the [research map](../research/RESEARCH-MAP.md): the **Goal** column names the shared goal (G1-G8) a result moves forward. **You can help.** If you own one of these devices, the stock tests in section 1 take minutes and need no flashing.

Each entry is a conclusion drawn by comparing projects. It follows from what is documented, but nobody has shown it on the device it is about. The units at hand for testing: **Digitakt II, Digitakt (mk1), Digitone II, Analog Heat +FX**.

How to use this page: pick an entry, run its test, and report what you saw, also when it contradicts the inference (that is just as useful).
- **Report:** open an issue with the **Test result** template (OS version, what you did, what happened, photos or captures if any), or a pull request that moves the fact into the device page with the evidence tag `[hw]`.
- **Maintainers:** move a confirmed entry to the device page and the research map's status table, then delete it here; a contradiction goes to [CONFLICTS.md](CONFLICTS.md).
- One report makes an entry 🟢 (shown once); a second unit or project makes it ✅.

Collected 2026-11-03.

**Kinds of test**
- **stock**: a stock OS and normal use, or a read-only tool on the computer. No flashing.
- **probe**: needs a read-only probe build (a USB PEEK, as in digikit, dnfw or 70b185's DT2 probe). The probe build itself is a modified OS, so it belongs in the firmware chat.
- **build**: needs a test build that does something on purpose.

- **Section 7 over 1 MiB** (A46): it corrupts the ColdFire heap before it is refused. The static reading and one accidental crash are enough.
- **A ColdFire hang without a watchdog**: expected to need a power cycle. Nothing is gained by provoking it.
